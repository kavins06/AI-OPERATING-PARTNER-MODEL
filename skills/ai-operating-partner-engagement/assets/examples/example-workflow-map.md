# Example Workflow Map

Workflow: Monthly operational report preparation
Owner: Operations manager
Users: Executive team, team leads
Trigger: Month-end close
Outcome: Approved report sent to leadership
Success metric: Reporting cycle time and correction rate

| Step | Actor | Action | Inputs | Systems/Sources | Decision | Output | Risk/Issue |
|---|---|---|---|---|---|---|---|
| 1 | Admin | Exports source data | System report | Core system, spreadsheet | None | Raw export | Export fields change |
| 2 | Analyst | Cleans and reconciles | Raw export, prior month | Spreadsheet | Resolve missing values | Clean table | Manual errors |
| 3 | Manager | Reviews exceptions | Clean table, notes | Dashboard, email | Approve or request fixes | Exception list | No clear threshold |
| 4 | Analyst | Drafts narrative | Metrics, exceptions | Slides/doc | Explain changes | Draft report | Narrative not source-linked |
| 5 | Executive | Reviews and approves | Draft report | Email/meeting | Approve send | Final report | Late corrections |

## Validation Questions

- Which source is authoritative?
- Which exceptions require escalation?
- What metric proves improvement?
