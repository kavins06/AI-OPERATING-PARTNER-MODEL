## Scoring

Score each dimension from 1 to 5.

| Dimension | 1 Means | 5 Means | Score | Evidence |
|---|---|---|---:|---|
| Business value | Nice-to-have or vague ROI | Direct revenue, cost, speed, risk, or service impact | | |
| Workflow clarity | Ad hoc, undocumented, disputed | Stable trigger, steps, owners, exceptions, and outcome | | |
| Data quality | Missing, stale, duplicated, contradictory | Trusted source of record with quality rules | | |
| Knowledge availability | Expertise lives only in heads | SOPs, examples, rules, edge cases, and review criteria exist | | |
| Analytics maturity | No trusted metrics or dashboards | Approved KPIs, semantic definitions, and dashboard evidence exist | | |
| Architecture feasibility | Manual exports or inaccessible systems | APIs, test data, retrieval sources, and tool boundaries are available | | |
| Privacy/security control | Sensitive data with unclear access | Least privilege, retention, approval, audit, and incident controls exist | | |
| Human oversight | No review owner or escalation path | Clear approval gates and exception handling | | |
| Measurement | Success cannot be measured | Baseline and target metrics are defined | | |

## Interpretation

- 38-45: strong pilot candidate.
- 29-37: proceed after fixing named gaps.
- 20-28: discovery, governance, data-quality, or knowledge-capture project first.
- Below 20: do not automate yet.
