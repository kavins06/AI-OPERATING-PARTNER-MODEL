## Combined Concept Bridge

| Analytics Concept | Information Management Concept | Combined Use |
|---|---|---|
| BI decision support | Sensemaking and decision making | Agents support decisions with evidence and context. |
| Data warehouse | Source of record and governance | Agents use trusted integrated data. |
| Semantic layer | Shared meaning and data dictionary | Agents do not invent metric definitions. |
| Dashboard KPIs | Information behavior and action | Agents explain exceptions and route next steps. |
| Statistics | Uncertainty and decision quality | Agents communicate confidence and avoid overclaiming. |
| Data mining | Knowledge creation | Agents discover patterns under human review. |
| Cloud analytics | Architecture and operating model | Infrastructure follows workload and governance needs. |
| Vector retrieval | Explicit knowledge and source traceability | Agents answer from approved documents with citations. |
| Data quality | Veracity and trust | Agents degrade, escalate, or refuse when data is weak. |
| Audit logs | Accountability and zero trust | Agent actions are traceable and reviewable. |

## Verification Rule

Use local corpus evidence for learning and internal strategy.

Before client-facing use, verify anything that depends on current:

- Law.
- Regulation.
- Privacy duties.
- Security standards.
- Vendor terms.
- Cloud products.
- Cloud pricing.
- Market facts.
- Business compliance obligations.
