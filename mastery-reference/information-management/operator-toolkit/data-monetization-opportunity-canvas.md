# Data Monetization Opportunity Canvas

Purpose: evaluate how a business firm can create value from data and AI agents.

Opportunity:
Segment: property management / residential brokerage / CRE / cross-segment

| Lens | Questions | Notes |
|---|---|---|
| Internal efficiency | What labor, rework, leakage, or delay can be reduced? | |
| Customer experience | What tenant, buyer, seller, investor, or broker experience improves? | |
| Decision quality | What decision gets faster, more accurate, or better evidenced? | |
| Data product | Can a governed reusable dataset or insight service be created? | |
| Risk reduction | What compliance, security, operational, or reputation risk falls? | |
| Revenue | What conversion, retention, pricing, or service expansion opportunity appears? | |

Quality checks:
- Monetization includes internal value, not only external data sales.
- Data rights and privacy constraints are checked.
- The value metric is measurable within a pilot window.
