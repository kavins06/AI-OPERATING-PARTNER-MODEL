# Mastery Curriculum

Target: operator-level mastery for building and managing AI agents for business firms.

Mastery rule: pass each module assessment at 85% before moving to capstones.

## Module Sequence

1. [Foundations: Information as an Organizational Capability](modules/01-foundations.md)
2. [Data Strategy and Governance](modules/02-data-strategy-governance.md)
3. [Knowledge Management and Information Sharing](modules/03-knowledge-management.md)
4. [Privacy, Security, Zero Trust, and Risk](modules/04-privacy-security.md)
5. [Data Monetization and Information Value](modules/05-data-monetization.md)
6. [Cases and Operating Lessons](modules/06-cases-operating-lessons.md)
7. [Business AI-Agent Delivery System](modules/07-business-ai-agents.md)

## Capstone Sequence

1. AI-agent readiness assessment for a property manager.
2. Data governance and privacy model for a residential brokerage.
3. CRE data strategy/use-case map for acquisition, diligence, reporting, and asset management.
4. Segment-agnostic managed-agent operating model with onboarding, monitoring, issue handling, and improvement loops.
