# Combined Data Analytics and Information Management Mastery

This folder combines the two existing mastery systems into one operator-ready reference set for building and managing business AI agents.

## Source Systems Combined

- `analytics/`: data analytics, BI, warehousing, dashboards, statistics, cloud analytics, governance, and AI-agent analytics artifacts.
- `information-management/`: information management, knowledge management, data strategy, privacy/security, zero trust, data monetization, curriculum, and operator templates.

## Core Thesis

Every AI agent is an information-management system first and an automation second.

The combined operating model is:

1. Business outcome.
2. Workflow discovery.
3. Information ecology map.
4. Source and system inventory.
5. Data readiness and quality controls.
6. Knowledge capture and knowledge map.
7. Governance, privacy, security, and zero-trust controls.
8. Warehouse, lakehouse, semantic layer, document intelligence, and analytics models.
9. Dashboards, KPI standards, retrieval, tools, and human review.
10. Managed AI-agent deployment, monitoring, audit, and improvement.

## Non-Negotiables

- No agent uses undefined metrics.
- No agent answers from stale or contradictory data without saying so.
- No sensitive workflow launches without least privilege, audit logging, and human approval.
- No legal, privacy, security, compliance, investment, or Fair Housing-sensitive claim is client-facing without current verification.
- No automation is sold before the workflow is clear, valuable, governable, measurable, and safe enough to pilot.
